Your workspace, ready.

A familiar XFCE desktop, a dependable Debian foundation.

Work and create

Write documents, build spreadsheets and present ideas with LibreOffice. Edit images with GIMP and keep quick notes in Mousepad.

Browse and connect

Firefox ESR is ready to use. Open Tor Browser from the application menu; its first launch downloads the browser and requires Internet access.

Tor Browser help

Your language

Select your language and keyboard during installation. Firefox includes all available Debian language packs; LibreOffice includes 32 language packs. Asian input methods and multilingual fonts are included.

Manage your system

Use Synaptic for software, Disks for storage and the network menu to connect. Printer and scanner settings are included.

Debian documentation

Obsidian

Obsidian is available from its publisher. Use Get Obsidian in the application menu to download the Linux installer. It requires Internet access and is not bundled with this ISO.

Download Obsidian

Install SventOS

In the live session, use Install SventOS on the desktop or in the application menu. The included desktop and applications can be installed without Internet access.

SventOS support

Use the Svent menu to explore applications. The live session opens directly to the desktop; your installed account uses the password you choose.
